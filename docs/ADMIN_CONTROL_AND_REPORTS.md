# 幹部控制中心、靜默問題清單與營運日報架構說明與未完成項目追蹤

本文件記錄「幹部群組控制中心」、「特定問題靜默名單」與「每日營運日報」三大擴充模組之架構設計、已建置的程式骨架，以及後續待進一步討論確認的細節項目。

---

## 一、目前已完成的基礎架構 (Scaffolded Architecture)

系統已建立清晰、低耦合的服務骨架，並於 Webhook 完成分流攔截與單元測試驗證：

```
src/
├── services/
│   ├── admin-control.ts      # 幹部控制中心服務（模式切換、狀態管理、群組指令處理）
│   ├── silent-questions.ts   # 靜默問題服務（關鍵字過濾、Excel 同步、幹部通報卡片）
│   ├── daily-reporter.ts     # 營運日報服務（每日數據聚合、Flex 戰報卡片、排程器）
│   └── group-whitelist.ts    # 新增 isAdminGroup() 幹部群組鑑權
├── handlers/
│   └── line-webhook.ts       # 整合幹部群組指令分流、1:1 靜默過濾、接管旁路
└── config/
    └── env.ts                # 新增 ADMIN_GROUP_ID 與 DAILY_REPORT_TIME 環境變數
```

### 1. 幹部控制中心 (`src/services/admin-control.ts`)
- **全域派單模式管理**：支援 `auto`（自動派單）與 `manual`（人工接管）兩種狀態切換。
- **指令分流**：僅在幹部群組 (`ADMIN_GROUP_ID`) 中觸發以下指令：
  - `接管` / `手動` / `暫停派單`：將系統切為人工模式，停止官方帳號 1:1 自動解析與回覆，人員可直接在 LINE OA 後台與客戶手動對話。
  - `恢復` / `自動` / `開啟派單`：切回自動派單模式，官方帳號即刻恢復自動接單流程。
  - `狀態` / `查狀態`：查詢目前系統運作模式與當前進行中之訂單數。

### 2. 靜默問題清單 (`src/services/silent-questions.ts`)
- **不回覆過濾器**：在 1:1 聊天室收到乘客訊息時，比對是否包含客訴、退費、遺失物、轉真人客服等敏感字詞。
- **命中時行為**：
  1. 機器人保持靜默，不發送自動回覆或歡迎詞，避免答非所問刺激客戶。
  2. 自動在「幹部群組」推播一張紅色警戒卡片（附上乘客姓名與原始提問），通知後台人員主動處理。
- **擴充性**：內建預設黑名單，並支援從 `config/派單系統參數表.xlsx`「靜默問題清單」頁籤自動載入。

### 3. 每日營運日報 (`src/services/daily-reporter.ts`)
- **排程機制**：伺服器啟動時掛載每日排程器（預設時間每日 `23:00`，由 `DAILY_REPORT_TIME` 控制）。
- **數據聚合**：自動從資料庫彙整「今日總進單數」、「成功媒合數」、「媒合率」、「流單數」、「估算營業額」與「活躍司機人數」。
- **戰報推播**：產出專屬高質感 LINE Flex Message 卡片，自動推送至幹部群組；亦支援在幹部群組輸入「`日報`」即時產出預覽。

## 二、待討論與未完成項目清單 (Pending Items for Discussion)

以下細節與呈現邏輯保留彈性，待後續與您逐一討論拍板：

### 📌 議題 1：幹部控制中心細節

- [ ] **接管防呆與逾時機制**：
  - 若人員切換為「手動接管」後忘記切回「自動」，是否需要：
    - (A) 每隔 1～2 小時在幹部群組溫馨提醒一次？
    - (B) 設定逾時自動恢復（例如接管超過 3 小時無操作自動切回自動模式）？
    - (C) 僅維持純手動切換，由人員完全掌控？
- [ ] **幹部身分鑑權顆粒度**：
  - 目前規則為「只要在幹部群組內發言」皆視為合法幹部。是否需要額外指定特定幹部的 `LINE User ID` 白名單，避免群內非授權人員誤觸指令？
- [ ] **接管範圍顆粒度**：
  - 目前為「全域接管」（所有乘客一律暫停機器人，改由人工客服回覆）。
  - 未來是否需要「單一乘客接管」（僅對特定有問題的乘客關閉機器人，其他正常叫車的乘客仍由機器人自動派單）？

### 📌 議題 2：特定問題與靜默清單呈現邏輯

- [ ] **命中時對乘客的體驗設計**：

  - (B) **客製化禮貌提示**：機器人回覆一則固定的制式訊息（例如：*「您的問題我們已收到，派單專員將盡速以人工方式為您回覆，請稍候！」*），回覆完後機器人隨即閉嘴。
- [ ] **Excel 參數表管理規格**：

- [ ] **幹部群組即時增修指令**：
  - 是否需要支援在幹部群組打字即時增刪關鍵字（例如輸入 `!新增靜默 優惠碼`、`!刪除靜默 優惠碼`）？

## 三、未來啟用步驟指南 (Deployment Guide)

待上述細節討論拍板並定案後，啟用此系統只需完成以下設定：

1. **取得幹部群組 ID**：
   - 將官方帳號機器人邀請加入您的「幹部群組」。
   - 在幹部群組中打字發送：`!groupid`。
   - 機器人將回傳群組 ID（如 `C1234567890abcdef...`）。
2. **設定環境變數**：
   - 在 `.env` 或雲端託管後台（如 Railway / Render）設定：
     ```bash
     ADMIN_GROUP_ID=C1234567890abcdef...
     DAILY_REPORT_TIME=23:00
     ```
3. **完成重啟**：重啟伺服器後，幹部控制中心、靜默警報與每日排程日報便正式上線運作。
